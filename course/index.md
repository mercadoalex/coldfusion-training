## What You Will Learn

This course is organized into six modules that progress from beginner to advanced. Each module contains short lessons and interactive labs that run inside the provided rootfs image.

- **Module 1** — Introduction, CFML syntax, variables, scopes, Application.cfc, HTML5 & multimedia
- **Module 2** — Datasources, SQL with cfquery, ORM, caching & chart generation
- **Module 3** — CommandBox, Lucee, REST APIs, WebSockets, SOAP web services & testing
- **Module 4** — Security hardening, performance tuning, CI/CD & production readiness
- **Module 5** — Java integration, XML handling, cloud deployments & CF administration
- **Module 6** — Scheduling, cross-technology integration, Apache Solr & complementary features

## Prerequisites

- Basic web-development knowledge (HTML, HTTP)
- Comfort with the Linux command line
- No local ColdFusion required: use the provided rootfs image
